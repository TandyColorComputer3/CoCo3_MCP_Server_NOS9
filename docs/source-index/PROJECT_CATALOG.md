## Nested collections worth separate indexing

`ASM/NITROS9` contains `CLOCKS`, `CMDS` (including `CC`, `MULTIVUE`, `SDC2`, `VIEW`), `DW`, `GIMEX/NEW`, `KERNEL`, `MODS`, `NITROS9_115_PATCHES`, `PIPE`, `RBF`, `SCF`, and `SYSGO`. The root also has `inetd.a` and `telnet.a`. These should become separate revision-aware units in Pass 2.

`ASM/GAMES` includes CARMEN, FSIM2, GLOOM3D (GC/ORG), INTERBANK, KLONDIK2, KORONIS, KYUMGAI, PACOS9, ROF, ROGUE, SHANGHAI, SIERRA, SUBSIM, THECITY and THEXDER. `BASIC09/GAMES` includes BATTLESHIP, BOMBAWAY, CHESS, GEMQUEST, KNIGHTS, MASMIND, POKER, QBERT09, SHANGHAIB09, STARTREK, STARWARS, STONES, WWPOKER, SPOKER, DUNGEONDEPTHS and STRANDED. Their original/port/disassembly lineage is not settled. The JSON records every nested directory.

## Provenance cautions with content evidence

- `ASM/BASIC09/basic09_ver101.asm:12` credits Microware and Motorola (1980); later history precedes the implementation. This is historical implementation material, not a current API specification.
- `ASM/NITROS9/KERNEL/krn.asm:2` identifies the NitrOS-9 Level 2 kernel. `SCF/vtio_beta6.asm:58` identifies EOU Beta 5 changes; the same file includes disassembly history. Preserve both lineages.
- `ASM/DESKMATE3/desk.asm:6` explicitly says disassembled; `ASM/SUPERCOMM/super.a:4` does too. Do not label these original vendor releases.
- `ASM/SHELL/shellplus2.2a.asm:4` says modified from a 2.2 disassembly. `ASM/GSHELL/gshell_ver1_0_1.asm` credits derived source.
- `ASM/ALIB/alib.intro` names Bob van der Poel and contains usage/copyright restrictions. Presence on this VHD is not blanket redistribution permission.
- `C/CONTROL/AboutCtrl.c:32` explicitly identifies the NitrOS-9 EOU Project. `C/MAMOU/mamou.c` credits Boisy G. Pitre; `C/VIEWGIF20/viewgif.c:1` credits Vaughn Cato.
- `BASIC09/GUIB30/Guib.b09` names Shawn Driscoll and Br. Jeremy. Other examples and games remain unknown unless their own headers establish attribution.

No license or build audit was performed; no complete source files are included in Git.
